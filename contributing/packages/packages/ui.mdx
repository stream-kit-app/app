# @stream-kit/ui

App-agnostic Svelte 5 UI primitives for Stream Kit. Used by the main app and provided to plugins through the plugin host import map.

**Location:** `packages/ui/`  
**NPM name:** `@stream-kit/ui` (public npm registry)

## Installation (plugin authors)

Zip plugins that use declarative page blocks do not need this package. Add it as a **dev dependency** when you build custom Svelte views or dashboard widgets:

```bash
npm install --save-dev @stream-kit/ui
```

At runtime the app resolves `@stream-kit/ui/*` from `static/plugin-host/` via the import map. **Do not bundle** `@stream-kit/ui` into your plugin entry. Match the npm version to the Stream Kit app version you target.

## Design rules

- **No app imports** — do not import from `packages/app`, `$lib`, SvelteKit routes, app stores, app i18n, or Tauri APIs
- **Theme tokens** — components use Tailwind utility classes; the app supplies design tokens and global styles
- **Stable exports** — subpath exports are part of the public contract for the plugin host
- **Svelte 5** — snippets, runes, and typed props throughout

Plugin authors define declarative menu pages through `@stream-kit/plugin` page schemas. They should **not** import Svelte components from this package for menu pages; the app renderer maps blocks to these components.

## Usage in the app

```svelte
<script lang="ts">
	import { Button } from '@stream-kit/ui/button';
	import { Alert } from '@stream-kit/ui/alert';
</script>
```

Or from the barrel export:

```ts
import { Button, Alert, tooltipSnippet } from '@stream-kit/ui';
```

## Page blocks

`@stream-kit/ui/blocks` renders declarative plugin pages. Block types include:

- `heading`, `text`, `alert`
- `stack`, `grid` — layout containers
- `badge`, `button`, `link`
- `form` — settings-style fields inside a page
- `table`, `log`, `code`, `separator`

Plugins describe pages with `PluginPageDefinition` from `@stream-kit/plugin`; the app passes those blocks to `PageBlockRenderer`.

## Tooltips

Prefer Svelte snippets for rich tooltip content:

```ts
import { tooltipSnippet } from '@stream-kit/ui/attachments';
```

Pass `tooltipSnippet(snippet, arg)` rather than building HTML strings in JavaScript. Use string tooltips only for trivial one-line text.

## Peer dependencies

Consumers must provide:

- `svelte` ^5
- `bits-ui` ^2
- `clsx`, `tailwind-merge`, `tailwind-variants`
- `runed`
- `@iconify/svelte`

## Build

This package ships **source** (`src/`) directly. There is no separate dist bundle:

```bash
pnpm --filter @stream-kit/ui check   # svelte-check
pnpm --filter @stream-kit/ui dev     # watch mode
```

The app plugin host resolves `@stream-kit/ui/*` subpaths through a generated import map (`build-plugin-host.mjs`).

## CodeMirror

`@stream-kit/ui/codemirror` bundles editor setup for JSON, JavaScript, and Svelte with optional LSP integration (`codemirror-languageserver`, `svelte-language-server-web`). Used for script editors and structured config fields in the app.
