# Packages

Stream Kit is a pnpm monorepo. Shared libraries live under `packages/`; first-party plugins live under `plugins/`; the public website lives in `site/`.

This section documents the six workspace packages in `packages/`.

## Package overview

| Package | NPM name | Role |
|---------|----------|------|
| [App](/docs/packages/app) | `@stream-kit/app` | Desktop application (SvelteKit + Tauri) and plugin host |
| [Core](/docs/packages/core) | `@stream-kit/core` | Platform-neutral runtime helpers shared by app and plugins |
| [Plugin](/docs/packages/plugin) | `@stream-kit/plugin` | Public TypeScript API for plugin authors |
| [UI](/docs/packages/ui) | `@stream-kit/ui` | Shared Svelte 5 UI primitives (published to npm for custom views) |
| [App types](/docs/packages/app-types) | `@stream-kit/app-types` | Compatibility re-export of the plugin API |
| [Plugin template](/docs/packages/plugin-template) | `@stream-kit/plugin-template` | Internal dev copy; public template at [plugin-starter](https://github.com/stream-kit-app/plugin-starter) |

## Dependency graph

```text
@stream-kit/app
├── @stream-kit/core
├── @stream-kit/plugin
│   └── @stream-kit/core
├── @stream-kit/ui
│   └── @stream-kit/core
└── (dev) first-party plugins from plugins/*

@stream-kit/app-types
└── @stream-kit/plugin

@stream-kit/plugin-template
├── @stream-kit/core
└── (dev) @stream-kit/app, @stream-kit/plugin
```

## Build order

Root `build:packages` uses [Turborepo](https://turbo.build) (`turbo.json`) with an explicit task graph (no `^build`, because several packages have cyclic *package* deps via type-only `@stream-kit/app` links). Cacheable builds:

1. `//#codegen` — plugin config stubs + `@stream-kit/script-api` types
2. `@stream-kit/core` — ESM bundle + declarations
3. `@stream-kit/plugin` — public `.d.ts` + runtime re-exports (depends on core + codegen)
4. `@stream-kit/ui` — type-check only (source is consumed directly)
5. First-party plugins under `plugins/*` (`@stream-kit/plugin-*`, excluding `plugin-template`)
6. `@stream-kit/app build:plugin-host` — import map + host bundles in `static/plugin-host/`

During development, `pnpm dev` builds plugins (cached on warm runs), then starts persistent watchers for core/plugin/ui/plugins, PocketBase, the marketing site, and the Tauri app. Docs are opt-in via `pnpm dev:all` or `pnpm dev:docs`.
