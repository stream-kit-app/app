# Packages

Stream Kit is a pnpm monorepo. Shared libraries live under `packages/`; first-party plugins live under `plugins/`; the public website lives in `site/`.

This section documents the six workspace packages in `packages/`.

## Package overview

| Package | NPM name | Role |
|---------|----------|------|
| [App](/docs/packages/app) | `@stream-kit/app` | Desktop application (SvelteKit + Tauri) and plugin host |
| [Core](/docs/packages/core) | `@stream-kit/core` | Platform-neutral runtime helpers shared by app and plugins |
| [Plugin](/docs/packages/plugin) | `@stream-kit/plugin` | Public TypeScript API for plugin authors |
| [UI](/docs/packages/ui) | `@stream-kit/ui` | Shared Svelte 5 UI primitives |
| [App types](/docs/packages/app-types) | `@stream-kit/app-types` | Compatibility re-export of the plugin API |
| [Plugin template](/docs/packages/plugin-template) | `@stream-kit/plugin-template` | Internal dev copy; public template at [plugin-starter](https://github.com/stream-kit-app/plugin-starter) |

## Dependency graph

```text
@stream-kit/app
├── @stream-kit/core
├── @stream-kit/plugin
│   └── @stream-kit/core
├── @stream-kit/ui
│   └── @stream-kit/core
└── (dev) first-party plugins from plugins/*

@stream-kit/app-types
└── @stream-kit/plugin

@stream-kit/plugin-template
├── @stream-kit/core
└── (dev) @stream-kit/app, @stream-kit/plugin
```

## Build order

The root `build:packages` script builds shared packages before the app plugin host:

1. `@stream-kit/core` — ESM bundle + declarations
2. `@stream-kit/plugin` — bundles public `.d.ts` and runtime re-exports (depends on core)
3. `@stream-kit/ui` — type-check only (source is consumed directly)
4. First-party plugins under `plugins/*`
5. `@stream-kit/app build:plugin-host` — import map + host bundles in `static/plugin-host/`

During development, `pnpm dev` runs watchers for UI, plugin API, core, all first-party plugins, and the Tauri app in parallel.
