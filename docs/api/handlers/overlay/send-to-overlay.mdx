## Configuration

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| Overlay | select | Yes | Select an overlay |
| Event | combobox | Yes | message |
| Payload | one-of | No | `{"username":"{username}","message":"{message}"}` |
