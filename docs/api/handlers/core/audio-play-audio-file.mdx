# Play audio file

| | |
| --- | --- |
| **Handler ID** | `core:core:audio:play-audio-file` |
| **Plugin** | Core |
| **Category** | Audio |

## Configuration

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| Audio file | select-file-or-folder | Yes | Local path or cloud file ref (`/api/files/...`). With **Keep cloud files offline** enabled, cloud refs show and play from the local cache when available; otherwise they stream via authenticated download. With an active plan, local paths are uploaded to the cloud automatically in the background. **Upload** / **Cloud** still work for manual picks. |
