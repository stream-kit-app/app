## Conditions

| Condition | Description |
| --- | --- |
| Sub tier | Restrict to a subscription tier (Tier 1, Tier 2, Tier 3, or Prime). |
| Username | Match chatter username (equals, contains, starts with, ends with). Leave empty to always match. |
