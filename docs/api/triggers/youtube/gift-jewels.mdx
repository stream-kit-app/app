| | |
| --- | --- |
| **Trigger ID** | `youtube:youtube:chat:gift-jewels` |
| **Plugin** | YouTube |
| **Category** | Chat |

## Conditions

| Condition | Description |
| --- | --- |
| Username | Match chatter username (equals, contains, starts with, ends with). Leave empty to always match. |
| Minimum Jewels | Minimum number of YouTube jewels in the gift event. |
