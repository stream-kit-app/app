# Installation

## Download

Download the latest Stream Kit installer from [stream-kit.app](https://stream-kit.app).

## Install

1. Run the installer (`.msi` or `.exe` from the release).
2. Launch **Stream Kit** from the Start menu or desktop shortcut.
3. On first boot the app creates default data folders and a **default** action queue.

## Updates

GitHub installer builds check for Stream Kit updates on startup. When a new version is available, the app asks before downloading and restarting (the installer closes Stream Kit on Windows). You can also check from **Settings → Updates**.

Microsoft Store installs update through the Store, not this in-app check.

## Data location

Stream Kit stores actions, variables, plugin settings, and overlays in your app data directory (managed by the desktop app). Use **Settings** in the app for paths and backup options when available.
